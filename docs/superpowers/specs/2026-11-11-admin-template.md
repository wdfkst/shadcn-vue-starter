# Vue 后台模板设计

用户批准：Vue 3 + Vite + shadcn-vue 风格组件，参考现有 React 项目布局样式，若依式通用管理功能；第一版仅前端，模拟接口，预留后端；重点是页面生成器。

## 交付
独立项目，不改变 React 项目。默认中文、侧栏折叠、移动侧栏、深浅主题、布局设置、菜单搜索、登录/退出、路由和操作权限。默认不显示多页签。
用户、角色、菜单、部门、字典、操作和登录日志；首版以通用列表/表单实现，部门层级和角色权限为编辑字段，不声称完整后端 RBAC 引擎。
通用 CRUD：查询、筛选、分页、列显隐、校验、新增编辑详情删除、导出。模拟数据本机持久化；真实接口切换不暗中回退到 mock。
生成器：模块名、标识、字段类型/列表/查询/必填/选项配置，预览与 JSON 导出；CLI 将可编辑 Vue 页面、schema、types、api、route、mock 写入项目，自动发现路由。默认拒绝覆盖任何目标文件，阻止路径逃逸和符号链接路径。

## 视觉
参照原项目 slate 主题 tokens、16rem 侧栏、64px 顶栏、内容区 px-4 py-6、原始圆角/边框/按钮与输入组件。使用 Reka UI 无障碍交互 primitives。第一版不承诺原项目每个页面逐像素复刻；要通过实际浏览器检查。

## 边界
没有真实服务器、数据库解析、真实 token、密码安全存储、多租户、生产审计。模拟权限仅演示，生产必须后端授权。生成器不做静默合并或覆盖。日志为只读示例，可记录本地操作但不是可信审计。
